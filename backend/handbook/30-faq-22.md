# Вопросы и ответы: Чего нет или не описано в справке

Частые вопросы пользователей QEVO по теме «Чего нет или не описано в справке» — с ответами и снимками экрана, где нужные кнопки обведены красным и пронумерованы по шагам.

## Есть ли диаграмма Ганта?

Ещё спрашивают: гант, gantt, временная шкала.

В справке Qevo диаграмма Ганта не описана. Для планирования есть доска, список, календарь, связи между задачами («ждёт эту задачу»), прогноз сроков в «Пульсе команды». Если Гант для вас критичен, нажмите «Позвать инженера» — подскажут, что можно сделать сейчас.

![Есть ли диаграмма Ганта? — где нажимать](/api/help/img/faq-a-116.webp)

## Есть ли подзадачи?

Ещё спрашивают: вложенные задачи, разбить задачу.

Да. В карточке задачи на вкладке «Обзор» есть блок «Подзадачи»: «Добавить подзадачу» создаёт новую, «Сделать подзадачей существующую» привязывает уже поставленную. У подзадачи виден блок «Родительская задача». На доске у карточки показан счётчик подзадач — сколько из них готово. Ещё внутри задачи есть чек-лист для мелких шагов.

![Есть ли подзадачи? — где нажимать](/api/help/img/faq-a-267.webp)

## Можно ли добавить свои поля в задачу?

Ещё спрашивают: кастомные поля, свои поля.

В справке пользовательские поля не описаны. Классифицировать задачи можно тегами («Личный кабинет» → «Теги задач»), направлениями и приоритетом. Если нужны собственные поля, спросите инженера, возможно ли это сейчас.

![Можно ли добавить свои поля в задачу? — где нажимать](/api/help/img/faq-a-268.webp)

## Есть ли спринты и Scrum?

Ещё спрашивают: скрам, burndown, бэклог.

Спринты в справке не описаны. Потоком работы можно управлять колонками доски, правилами «Когда — тогда» и прогнозом в «Пульсе команды». Для Scrum-процесса уточните у инженера, что есть сейчас.

![Есть ли спринты и Scrum? — где нажимать](/api/help/img/faq-a-269.webp)

## Есть ли API или вебхуки?

Ещё спрашивают: api qevo, интеграция через api.

В справке для пользователей API не описан. Из интеграций есть входящий вебхук Битрикс24, Google, почта, Telegram. По API лучше спросить инженера.

![Есть ли API или вебхуки? — где нажимать](/api/help/img/faq-a-270.webp)

## Можно ли печатать или экспортировать доску в PDF?

Ещё спрашивают: печать доски, экспорт.

В справке есть PDF-отчёт по задачам («Личный кабинет» → «Отчёты») и выгрузка клиентов в CSV. Экспорт самой доски не описан — спросите инженера.

![Можно ли печатать или экспортировать доску в PDF? — где нажимать](/api/help/img/faq-a-271.webp)

## Есть ли интеграция с 1С, Jira, GitHub?

Ещё спрашивают: 1с, github, jira интеграция.

В справке этого нет. Доступны: Google, почта, Telegram, Битрикс24 (вебхук) и YouGile, импорт из Trello/Notion/файлов. Остальное спросите у инженера через «Позвать инженера».

![Есть ли интеграция с 1С, Jira, GitHub? — где нажимать](/api/help/img/faq-a-270.webp)

## Это есть в других трекерах, а здесь я не нашёл. Что делать?

Ещё спрашивают: как в jira, как в trello, в asana было.

Скажите, что именно вы ищете и как делали это раньше: подскажу ближайший способ в Qevo. Если функции нет в справке, я не буду придумывать — нажмите «Позвать инженера», он подтвердит или передаст пожелание в команду.
