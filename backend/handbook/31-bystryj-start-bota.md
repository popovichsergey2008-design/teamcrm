# Быстрый старт QEVO Bot: что попросить и что для этого нужно

QEVO Bot → «Что умею»: десять направлений с готовыми просьбами. Нажмите направление, затем просьбу — бот возьмёт данные QEVO и ответит. Всё, что что-то меняет (письма, встречи, задачи, напоминания), бот сначала показывает карточкой на подтверждение. Ниже по каждой просьбе: что бот сделает, что нужно подключить и где это найти в QEVO самому.

![QEVO Bot → «Что умею»: десять направлений с готовыми просьбами](/api/help/img/bs-bot-1.webp)

## Управление электронной почтой: что нужно боту

Что нужно: подключить свою почту. Путь: в левом меню «Ещё» → «Личный кабинет» → карточка «Почта» → выберите сервис (Gmail, Яндекс, Mail.ru, Outlook или свой сервер) → введите адрес и пароль приложения → «Подключить». Пароль приложения — не обычный пароль от почты: в Gmail его создают в «Аккаунт Google → Безопасность → Двухэтапная аутентификация → Пароли приложений», в Яндексе — «Яндекс ID → Безопасность → Пароли приложений», в Mail.ru — «Настройки → Безопасность → Пароли для внешних приложений». Письма видите только вы; бот ничего не отправляет сам — черновик ляжет в «Черновики» вашего ящика, отправка только по вашей кнопке.

![«Ещё» → «Личный кабинет» → карточка «Почта»](/api/help/img/bs-mail-1.webp)

![«Почта»: выберите сервис, введите адрес и пароль приложения, нажмите «Подключить»](/api/help/img/bs-mail-2.webp)
