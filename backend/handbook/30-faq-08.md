# Вопросы и ответы: Общие задачи

Частые вопросы пользователей QEVO по теме «Общие задачи» — с ответами и снимками экрана, где нужные кнопки обведены красным и пронумерованы по шагам.

## Где посмотреть задачи по всем проектам сразу?

Ещё спрашивают: общие задачи, мои задачи по всем проектам.

«Проекты и Задачи» → «Общие задачи» (кнопка есть и на каждой доске). Быстрее: Ctrl K → «Задачи: мои по всем проектам». Раздел открывается срезом «Мои задачи», где у вас любая роль.

![Где посмотреть задачи по всем проектам сразу? — где нажимать](/api/help/img/faq-a-132.webp)

## Как посмотреть, что я поручил другим?

Ещё спрашивают: задачи которые я поставил, поручил.

В «Общих задачах» нажмите стрелку рядом с «Мои задачи» и оставьте отмеченной только роль «Поручил». В этом срезе вместо постановщика показан исполнитель. Для руководителей ещё «Все задачи компании» для разбора и контроля.

![Как посмотреть, что я поручил другим? — где нажимать](/api/help/img/faq-a-133.webp)

## Не вижу завершённую задачу

Ещё спрашивают: где закрытые задачи, архив задач.

Включён переключатель «В работе» — он показывает только живую работу. Нажмите его, и он станет «Всё, включая архив»: появятся завершённые задачи и задачи из архивных проектов.

![Не вижу завершённую задачу — где нажимать](/api/help/img/faq-a-134.webp)

## Почему список задач пустой?

Ещё спрашивают: ничего не отображается, пустая таблица.

Проверьте фильтры: если что-то выбрано, нажмите «Сбросить». В срезе «Поручил» список пуст, если вы пока никому не поручали задач.

![Почему список задач пустой? — где нажимать](/api/help/img/faq-a-135.webp)

## Как быстро найти задачу по номеру?

Ещё спрашивают: найти по номеру.

В «Общих задачах» введите номер в «Поиск по названию или номеру…». Или Ctrl K и номер.

![Как быстро найти задачу по номеру? — где нажимать](/api/help/img/faq-a-136.webp)
