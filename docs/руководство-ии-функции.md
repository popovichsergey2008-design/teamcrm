# Руководство: ИИ-функции и командная работа

Практическое руководство по нововведениям TEAMCRM (июль 2026). Для пользователей и внедренцев:
что это, кто видит, как пользоваться, ограничения.

> **Важно про ИИ-ключ.** Все ИИ-функции работают в двух режимах:
> - **С ключом** (реальный ИИ) — нужен ключ OpenAI / Anthropic / OpenRouter. Подключается в
>   **Интеграции → ИИ** (BYOK, свой ключ на организацию) или в глобальном `.env` сервера.
>   Для распознавания речи (голос) нужен именно ключ **OpenAI (Whisper)**.
> - **Без ключа** (демо/mock) — интерфейс и логика работают, но ответы ИИ — заглушки,
>   а распознавание речи возвращает пустой текст с подсказкой. Ничего не ломается.

---

## 1. Быстрая команда: текст и голос (Zero-UI)

**Что это.** Создание задачи или сделки обычным языком — пишете или диктуете, ИИ понимает и
предлагает готовый черновик, вы подтверждаете. Ничего не создаётся без вашего подтверждения.

**Кто видит.** Кнопка **⚡ Команда** в верхней панели — owner, manager, member.

**Как пользоваться (текст):**
1. Нажмите **⚡ Команда**.
2. Напишите фразу, например: *«Иванову задача обновить баннер на главной к пятнице, срочно»*.
3. Нажмите **✨ Распознать** — ИИ определит: задача это или сделка, подставит проект/исполнителя/срок/приоритет.
4. Проверьте и при необходимости поправьте поля → **Создать задачу** (или сделку).

**Как пользоваться (голос):**
1. Нажмите **🎤 Записать голосом** → продиктуйте команду → **⏺ Остановить и распознать**.
2. Распознанный текст попадёт в поле команды → дальше как обычно (**✨ Распознать** → подтверждение).

**Ограничения.** Голос требует ключа OpenAI (Whisper). Имена проектов/людей/клиентов ИИ сопоставляет
только с реальными из вашей организации — если не уверен, оставляет поле пустым (выберете вручную).

## 2. Входящие → авто-задачи (Inbox)

**Что это.** Письма и сообщения превращаются в черновики задач. Есть два источника:
пересылка на **вебхук канала** (почта/мессенджер/Zapier/n8n) и **голосовая заметка** прямо в приложении.
Всё проходит ревью — задача создаётся только после подтверждения.

**Кто видит.** Кнопка **📥 Входящие** — owner, manager.

### 2.1. Каналы приёма (вебхук)
1. **📥 Входящие → вкладка «Каналы» → «Создать канал»** (название + проект по умолчанию — необязательно).
2. Скопируйте **вебхук-URL** канала и укажите его в почтовом провайдере / Zapier / n8n как приёмник входящих.
3. Поддержаны форматы Mailgun / Postmark и общий JSON/form с полями `from` / `subject` / `body`.
   Поддерживается и `multipart/form-data` (как шлёт Mailgun с вложениями — вложения игнорируются, берётся текст).

### 2.2. Голосовая заметка
1. **📥 Входящие → вкладка «Черновики» → 🎤 Надиктовать задачу** → продиктуйте → остановите.
2. ИИ распознает речь и добавит черновик в список (помечен как «Голос»).

### 2.3. Ревью черновиков
В «Черновиках» по каждому входящему: поправьте название/проект/исполнителя/приоритет →
**Создать задачу** или **Отклонить**.

**Ограничения.** Осмысленное распознавание текста письма и голоса требует ИИ-ключа
(для голоса — OpenAI/Whisper). Управление входящими — только owner/manager.

## 3. Спросить ИИ по базе знаний (со «стримингом»)

**Что это.** «Корпоративный разум» отвечает на вопросы по архиву компании (задачи, комментарии,
регламенты, Google-доки) со ссылками на источники. Ответ **печатается по мере генерации**, как в ChatGPT.

**Кто видит.** Кнопка **База знаний → вкладка «Спросить ИИ»** — owner, manager, member.

**Как пользоваться:**
1. Откройте **База знаний → Спросить ИИ**.
2. Задайте вопрос, например: *«Как мы решали пагинацию на проектах недвижимости?»*
3. Ответ появляется постепенно, снизу — ссылки на источники `[1] [2]`. Оцените ответ 👍/👎 (это улучшает промпты).
4. Можно сузить поиск до конкретного проекта (фильтр разреза).

**Ограничения.** Живой «набор» текста виден при подключённом ключе; без ключа печатается демо-ответ.
Ответ строится только по проиндексированной базе — если материалов нет, ИИ честно об этом скажет.

## 4. Многоразовая ссылка-приглашение в организацию

**Что это.** Одна ссылка — много участников. Каждый переходит по ней и заводит **свой** аккаунт
(свой e-mail, имя, пароль). Удобно кинуть в общий чат. В отличие от одноразового приглашения на конкретный email.

**Кто видит.** **Команда → вкладка «Сотрудники» → «Многоразовая ссылка»** — owner, manager.

**Как пользоваться:**
1. **Команда → Сотрудники → Многоразовая ссылка**: выберите роль (**Участник** или **Менеджер**),
   при желании — **лимит входов** и **срок действия** (оба необязательны).
2. Нажмите **Создать многоразовую ссылку** → скопируйте её и раздайте.
3. Ниже — список активных ссылок со счётчиком «вошло N из M». Любую можно **Отключить**.
4. Приглашённый открывает ссылку, видит название организации и роль, вводит имя/e-mail/пароль → **Вступить**.

**Ограничения / безопасность.** Через открытую ссылку можно выдать только роль **Участник** или **Менеджер**
(не владельца и не клиента). Ссылка перестаёт работать при исчерпании лимита, истечении срока или отключении.
Создавать и отключать ссылки могут только owner/manager.

## 5. ИИ-агент: черновик решения задачи

**Что это.** ИИ-агент читает задачу и базу знаний компании и предлагает **черновик решения**
(план по шагам, что проверить, подводные камни). Результат появляется комментарием на ревью —
**агент ничего не меняет в задаче сам**, решаете вы (human-in-the-loop).

**Кто видит.** Вкладка **🤖 Агент** в карточке задачи — owner, manager.

**Как пользоваться:**
1. Откройте задачу → вкладка **🤖 Агент** → **✨ Запустить агента** (кнопка покажет «Агент думает…»).
2. Черновик появится в списке запусков и в «Обсуждении» задачи с пометкой «🤖 Черновик от ИИ-агента».
3. Ревью результата:
   - **Принять** — черновик остаётся как есть (комментарий).
   - **В чеклист** — разложить черновик на пункты чек-листа задачи.
   - **Отклонить** — убрать черновик-комментарий.
4. По каждому запуску виден статус и примерная стоимость в токенах.

**Ограничения.** Запуск — только owner/manager. Есть лимит **30 запусков в час** на организацию
(защита от лишнего расхода). Осмысленный ответ — при подключённом ИИ-ключе.

## 6. Полная себестоимость (cost of work): люди + ИИ

**Что это.** Реальная стоимость работы = **труд людей** (часы из тайм-трекера × ставки) +
**работа ИИ-агента** (токены запусков агента по задачам проекта). Всё в одном месте.

**Кто видит.** Панель **P&L проекта** (когда включена монетизация) — owner, manager, member.

**Как читать виджет:**
- **Труд (N ч)** — сколько человеко-часов и на какую сумму.
- **ИИ-агент (~токенов)** — сколько потратил ИИ-агент (число запусков — в подсказке), оценка стоимости «≈».
- **Полная себестоимость** — труд + ИИ вместе.

**Ограничения.** В себестоимость входит только **агентский** ИИ (он привязан к задаче).
Фоновый ИИ (вопросы к базе знаний, поиск) — общий по организации и по проектам не разносится.
Оценка ИИ-стоимости приблизительная (по токенам), расход в токенах — точный.

## Справочник API (для интеграторов)

Все эндпоинты — под JWT, префикс `/api`. Роли указаны там, где отличаются от общих.

| Функция | Метод и путь | Роли |
|---|---|---|
| Разобрать команду (текст) | `POST /nl/parse` | owner/manager/member |
| Применить черновик | `POST /nl/apply` | owner/manager/member |
| Распознать голос → текст | `POST /nl/transcribe` (multipart `audio`) | owner/manager/member |
| Каналы входящих | `GET/POST /inbox/sources`, `DELETE /inbox/sources/:id` | owner/manager |
| Приёмник вебхука | `POST /inbox/hook/:token` (публичный) | — |
| Голосовая заметка → черновик | `POST /inbox/voice` (multipart `audio`) | owner/manager |
| Ревью входящих | `GET /inbox/items`, `POST /inbox/items/:id/confirm`, `.../dismiss` | owner/manager |
| Спросить ИИ (стрим SSE) | `POST /brain/conversations/:id/ask/stream` | owner/manager/member |
| Многоразовая ссылка | `GET/POST /invites/links`, `DELETE /invites/links/:id` | owner/manager |
| Инфо о ссылке / вступление | `GET /invites/links/:token/info`, `POST /invites/links/accept` | публичные |
| Запуск ИИ-агента | `POST /agents/tasks/:taskId/run` | owner/manager |
| История запусков | `GET /agents/tasks/:taskId/runs` | owner/manager |
| Ревью результата агента | `POST /agents/runs/:id/accept` (`{toChecklist?}`), `.../reject` | owner/manager |
| Полная себестоимость | `GET /tasks/:id/cost-of-work`, `GET /projects/:id/cost-of-work` | internal (не client) |

**Настройка стоимости ИИ.** Ориентировочная цена работы ИИ задаётся переменной окружения
`AI_COST_PER_1K_TOKENS` (цена за 1000 токенов, в той же денежной единице, что и ставки; по умолчанию `0.01`).
