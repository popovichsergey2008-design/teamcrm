# Знак ANTHILL.TEAM

`anthill-logo-source.jpg` — оригинал от заказчика (1024×1024, неон по тёмному,
знак сверху, слово ANTHILL.TEAM снизу). Лежит в репозитории специально: из него
нарезаны все иконки приложения, и без исходника перерезать их было бы нечем.

## Что из него сделано

| Файл в `frontend/public` | Что это | Откуда |
|---|---|---|
| `logo-mark.png` (512) | знак в приложении — панель, вход, портал, гостевые экраны | кадр 670×670 вокруг знака |
| `icon-512.png` | иконка для «добавить на главный экран» | тот же кадр |
| `icon-192.png`, `apple-touch-icon.png` (180) | иконки телефона | кадр плотнее — мелкие размеры теряют тонкие линии |
| `favicon-32.png`, `favicon-64.png` | знак вкладки | тот же плотный кадр + резкость и цвет |
| `logo-full.png` (640) | логотип целиком, вместе со словом | вся картинка |

## Как перерезать

Слово в исходнике начинается с 808-го пикселя по высоте — рамка знака обязана
заканчиваться выше, иначе в иконку попадают верхушки букв. Центр знака — (512, 465).
Фон исходника не чёрный, а «грязный» от JPEG: перед уменьшением тёмное выравнивается
в один цвет `#0b0d12`, иначе на мелком размере вокруг знака виден серый шум.

Отдельного скрипта нет намеренно: перерезать приходится раз в год, а скрипт с
графической библиотекой пришлось бы тащить в зависимости фронтенда навсегда.
Нарезка делалась Pillow'ом на машине разработчика — команды записаны в истории
коммита «фирменный знак ANTHILL.TEAM везде».

## Чего НЕ делаем

Не вырезаем фон под прозрачность: знак нарисован свечением по тёмному, и без своей
подложки он рассыпается — на белом фоне остаются бледные линии без свечения. Поэтому
знак живёт скруглённой плиткой, как иконка приложения.
