# Вопросы и ответы: Клиенты и сделки

Частые вопросы пользователей QEVO по теме «Клиенты и сделки» — с ответами и снимками экрана, где нужные кнопки обведены красным и пронумерованы по шагам.

## Где находится раздел «Клиенты»?

Ещё спрашивают: crm, не вижу клиентов.

«Ещё» → «Личный кабинет» → карточка «Клиенты». Она есть у владельца и руководителей. Сотрудник видит клиента через поле «Клиент» в задаче.

![Где находится раздел «Клиенты»? — где нажимать](/api/help/img/faq-a-217.webp)

## Как добавить клиента?

Ещё спрашивают: новый клиент, создать клиента.

«Новый клиент» → тип (компания или частное лицо) → название, контактное лицо, телефон, почта, ответственный, источник, сайт → «Создать». Если есть похожий, Qevo предупредит: можно открыть существующего или нажать «Создать всё равно».

![Как добавить клиента? — где нажимать](/api/help/img/faq-a-218.webp)

## Как импортировать клиентов из файла?

Ещё спрашивают: загрузить клиентов, csv клиентов.

«Импорт» → файл CSV или Excel (.xlsx) с заголовками в первой строке → проверьте соответствие колонок (ненужные отметьте «Не загружать») → выберите, что делать с похожими → «Импортировать». В конце будет отчёт: загружено, пропущено, отложено на проверку.

![Как импортировать клиентов из файла? — где нажимать](/api/help/img/faq-a-219.webp)

## Как выгрузить клиентов?

Ещё спрашивают: экспорт клиентов.

Клиентов можно выгрузить в «Клиенты → Выгрузить» (CSV), журнал изменений задач в «Пульс команды» (CSV), отчёт по задачам в PDF в «Личный кабинет → Отчёты». Файлы скачиваются вручную. Полную выгрузку можно заказать в «Помощь и бот», это сделает Отдел заботы.

![Как выгрузить клиентов? — где нажимать](/api/help/img/faq-a-220.webp)

## Как создать сделку?

Ещё спрашивают: воронка, стадии сделки, сумма сделки.

В карточке клиента вкладка «Сделки» → «Создать сделку»: название, сумма и валюта, вероятность, стадия, ответственный, дата закрытия, следующий шаг. Стадии: Новая, Переговоры, Предложение, Согласование, Выиграна, Проиграна (у проигранной нужна причина). Заводят и правят сделки руководители.

![Как создать сделку? — где нажимать](/api/help/img/faq-a-221.webp)

## Что значит полоса «Дальше» в карточке клиента?

Ещё спрашивают: следующий шаг по клиенту.

Самое важное по клиенту: ближайшая задача со сроком. Если следующего шага нет, Qevo предложит «Создать задачу» или «Запланировать встречу». Свой вариант записывается кнопкой «Записать своё».

![Что значит полоса «Дальше» в карточке клиента? — где нажимать](/api/help/img/faq-a-222.webp)

## Почему вместо телефона клиента звёздочки?

Ещё спрашивают: скрытые контакты, показать телефон.

Владелец включил скрытие контактов. Нажмите «Показать» (Qevo может спросить, зачем) — просмотр попадёт в журнал.

![Почему вместо телефона клиента звёздочки? — где нажимать](/api/help/img/faq-a-223.webp)

## Как объединить двух одинаковых клиентов?

Ещё спрашивают: дубликаты клиентов, слить клиентов.

Откройте клиента, который должен остаться, нажмите «Объединить», найдите дубликат, сравните данные и выберите название. Контакты, сделки, проекты, задачи, встречи, заметки и файлы второго переедут в первого.

![Как объединить двух одинаковых клиентов? — где нажимать](/api/help/img/faq-a-224.webp)

## Как удалить клиента?

Ещё спрашивают: убрать клиента.

Сначала в архив («В архив»), потом у архивного клиента появится «Удалить» — если у вас есть право. Задачи и проекты останутся без привязки к клиенту. Из архива клиента можно вернуть в любой момент.

![Как удалить клиента? — где нажимать](/api/help/img/faq-a-225.webp)

## Что показывает «QEVO AI — кратко о клиенте»?

Ещё спрашивают: сводка по клиенту, ии про клиента.

Несколько строк о главном: активен ли клиент, когда была активность, сколько открытых задач, риски. Сводка строится только по фактам из Qevo, кнопка «Почему?» показывает основания. Если данных мало, будет «Недостаточно данных для вывода».

![Что показывает «QEVO AI — кратко о клиенте»? — где нажимать](/api/help/img/faq-a-226.webp)
