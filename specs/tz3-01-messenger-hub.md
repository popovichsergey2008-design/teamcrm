# ТЗ-3, этап 1 — «Миты и мессенджеры»: единая рабочая среда

Источник: разбор Slack (каналы, треды, Huddles, Canvas, Clips, Connect, Later, Activity,
сайдбар) и решение переносить **связку**, а не отдельные функции:

> чат → контекст → быстрые действия → голос/мит → история → AI

Slack здесь UX-референс, а не список для копирования. Главное отличие ANTHILL: чат знает,
с какой сущностью CRM он связан, и умеет превращать разговор в работу.

## Архитектурная идея (то, ради чего всё затевается)

```
Message → Channel | Thread
        → связан с Task | Project | Client
        → может ПОРОДИТЬ Task

Meeting → связан с Conversation
        → Transcript → Summary → Tasks

AI      → видит только тот контекст, который разрешён текущему пользователю
```

Не «CRM, куда прикрутили чат», а одна система: из задачи — в сообщение, из сообщения — в
задачу, из чата — в созвон, из созвона — обратно в чат.

## Чего НЕТ (предмет этого ТЗ)

**Ядро мессенджера**
- каналы как отдельный тип: публичные (видны всем, вступление самому) и приватные;
- «Все каналы» — витрина с кнопкой «Вступить»;
- @упоминания в мессенджере (есть только в чате задачи и в ленте компании);
- чат с собой («Заметки»).

**То, что делает чат рабочим инструментом**
- **треды** — обсуждение конкретного сообщения, основной канал остаётся чистым;
- раздел «Треды»: где ответили, где упомянули, где я участвовал;
- реакции на сообщения мессенджера;
- закрепление сообщений (`📌 Закреплено: 4`);
- «Сохранить на потом» + раздел «Сохранённое»;
- «Напомнить мне» (через час / вечером / завтра / дата);
- «Входящие»: упоминания, ответы в тредах, приглашения, AI-события в одной ленте;
- «Непрочитанные» единой лентой, а не точками по чатам;
- избранное и пользовательские секции в сайдбаре чатов.

**Связь с CRM (главное преимущество)**
- шапка чата с данными сущности: проект, статус, ответственный, дедлайн, кнопки;
- вкладка «Информация» у чата (упрощённый Canvas): описание, ссылки, договорённости,
  чек-лист, контакты;
- **создать задачу из сообщения** — с AI-постановкой и чек-листом;
- обратная ссылка: в задаче «создано из сообщения», под сообщением «✅ Задача #1434»;
- привязка сообщения к проекту / задаче / клиенту;
- чат задачи виден и в разделе мессенджера, не только в карточке;
- чат клиента и разделение внутреннего и клиентского чата проекта.

**Миты**
- мит остаётся привязанным к чату: после завершения в чат приходит карточка
  «Мит завершён · 43 мин» + Summary + список созданных задач.

**Clips**
- голосовое сообщение в чат с автоматической расшифровкой;
- запись экрана с голосом (показать баг), из неё — задача.

**AI**
- `@AI` в любом чате по разрешённой этому человеку истории;
- AI-сводка непрочитанных («47 непрочитанных» → «✨ Кратко»);
- «Что я пропустил сегодня?»;
- AI-поиск по переписке с ссылкой на сообщение.

**Внешние**
- внешний чат с клиентом по ссылке, без доступа к остальному;
- явная пометка «Внешний пользователь» в смешанных чатах.

## Чего НЕ делаем сознательно

Workflow Builder, полноценный Canvas, федерация уровня Slack Connect, enterprise-DLP,
приложения внутри каналов, сложная система ботов. Каждое — отдельный продукт внутри
продукта; браться за них сейчас значит не доделать основное.

## Порядок работ

Отсортировано по практической пользе, а не по названиям функций Slack. В скобках — оценка.

**Слой 1. Разговор перестаёт разъезжаться** (~1–2 дня)
1. Треды в мессенджере + раздел «Треды».
2. Реакции на сообщения.
3. Закрепления.

**Слой 2. Ничего не теряется** (~1 день)
4. «Сохранить на потом» + раздел «Сохранённое».
5. «Напомнить мне» о сообщении.
6. «Входящие»: упоминания + ответы в тредах + непрочитанное одной лентой.
7. @упоминания в мессенджере.

**Слой 3. Чат = работа** (~2 дня) — здесь главное преимущество
8. Создать задачу из сообщения (AI-постановка + чек-лист + обратная ссылка).
9. CRM-шапка чата проекта; вкладка «Информация».
10. Привязка сообщения к сущности; чат задачи в разделе мессенджера.

**Слой 4. Каналы и сайдбар** (~1 день)
11. Публичные и приватные каналы, витрина «Все каналы», вступление.
12. Избранное, секции, перетаскивание в сайдбаре чатов.
13. Чат с собой.

**Слой 5. Миты внутри разговора** (~0.5 дня)
14. Карточка мита в чате после завершения: длительность, Summary, созданные задачи.

**Слой 6. AI в переписке** (~1–2 дня)
15. `@AI` в любом чате по разрешённой истории.
16. Сводка непрочитанных и «что я пропустил».
17. AI-поиск с ссылкой на сообщение.

**Слой 7. Clips** (~1 день)
18. Голосовое сообщение с расшифровкой.
19. Запись экрана; задача из записи.

**Слой 8. Внешние** (~1 день)
20. Внешний чат клиента, пометка внешнего участника, разделение внутреннего и
    клиентского чатов проекта.

## Границы, которые нельзя нарушать

- **AI видит только разрешённое.** Ответ по чужой переписке — утечка, а не удобство.
- **Клиент не видит внутреннее.** Внутренний и клиентский чаты проекта — разные чаты,
  а не один с фильтром: «клиент опять поменял требования» не должно уехать клиенту.
- **Кнопка, спрятанная до наведения, не существует.** Проверено дважды на живых людях.
- **Права интерфейса = права сервера.** Показанная кнопка, на которую сервер отвечает
  «недостаточно прав», хуже отсутствующей.
